# Security Policy

## Supported Versions

Only the latest release of Porchlight receives security updates and bug fixes.

| Version | Supported          |
| ------- | ------------------ |
| 0.13.x  | :white_check_mark: |
| < 0.13  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Porchlight, report it privately via
[GitHub Private Vulnerability Reporting](https://github.com/cawalch/porchlight/security/advisories/new).

Do not disclose security issues in public GitHub issues, discussions, or pull requests.

We take security reports seriously and will acknowledge receipt within 48 hours, investigate the issue, and provide a coordinated disclosure and patch timeline.
