Porchlight provides a deterministic CSS size budget. While the full 59-component monolithic bundle is ~32.5 KB gzipped (~25.7 KB Brotli), production applications do not need to ship all 59 components.

By combining Porchlight's `core.css` with only the components required for a specific surface, production payloads typically measure between **4.9 KB and 6.8 KB gzipped** (-52% to -65% smaller than traditional 14 KB monolithic CSS frameworks).

## Core and foundation bundles

Every Porchlight composition starts with `core.css` (which contains layer ordering, CSS reset, design tokens, color themes, and HTML element defaults).

| Bundle                                 | Raw Minified | Gzip    | Brotli  | Description                                                               |
| -------------------------------------- | ------------ | ------- | ------- | ------------------------------------------------------------------------- |
| `@cawalch/porchlight/core.css`         | 8.8 KB       | 2.7 KB  | 2.3 KB  | Layer order, reset, tokens, themes, and base element defaults.            |
| `@cawalch/porchlight/layout.css`       | 2.9 KB       | 0.96 KB | 0.80 KB | Stack, cluster, grid, center, and app-shell layouts.                      |
| `@cawalch/porchlight/utilities.css`    | 2.9 KB       | 0.88 KB | 0.75 KB | Typography, tabular lining numbers, and spacing utilities.                |
| `@cawalch/porchlight/enhancements.css` | 4.7 KB       | 1.1 KB  | 0.93 KB | Progressive enhancement rules (`text-box-trim`, style container queries). |
| `@cawalch/porchlight/compat.css`       | 221.7 KB     | 31.8 KB | 25.3 KB | Monolithic bundle excluding progressive enhancements.                     |
| `@cawalch/porchlight/full.css`         | 226.4 KB     | 32.5 KB | 25.8 KB | Canonical full bundle including all 59 components and enhancements.       |

## Production recipes: core + N components

Production applications achieve the smallest payloads by loading `core.css` plus their required component stylesheets.

### Recipe 1: Minimal Form & Controls (5.0 KB gzip)

Ideal for authentication screens, modal dialogs, and basic form inputs:

| Component / Bundle      | Gzip        | Brotli      |
| ----------------------- | ----------- | ----------- |
| `core.css`              | 2.70 KB     | 2.28 KB     |
| `components/button.css` | 1.09 KB     | 0.94 KB     |
| `components/field.css`  | 2.25 KB     | 1.83 KB     |
| **Combined Bundle**     | **5.05 KB** | **4.38 KB** |

## Size budget enforcement in CI

Porchlight maintains a continuous integration size budget gate:

1. Every release build generates `dist/size-budget.json` via `packages/porchlight/scripts/build.mjs`.
2. Any unintentional regression in individual component payloads or monolithic bundles is detected automatically before merge.
3. Bundle metadata is exported under `@cawalch/porchlight/size-budget.json` for consumption by external packaging bots and dashboard analysis.
