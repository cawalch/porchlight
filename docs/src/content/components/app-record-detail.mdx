# Record Detail

<a href={`${import.meta.env.BASE_URL}preview/app-record-detail`}>
  Open the record-detail app
</a>
.

This composition combines the app shell, page header, cards, description lists,
and <a href={`${import.meta.env.BASE_URL}components/section-nav`}>Section Navigation</a>.
A wide content container keeps navigation beside the record; narrow containers
place it in ordinary document flow above the sections. Each card has a stable
fragment ID for keyboard navigation and shareable deep links.
