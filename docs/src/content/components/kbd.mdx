---
title: Kbd (Keycap)
description: Tactile 3D mechanical keycaps for hotkeys, shortcuts, and command menus.
status: stable
since: 0.14.0
---

The `.pl-c-kbd` component styles keyboard shortcuts and hotkey combos. Designed with 3D physical bevel shadows, monospaced centering, and tactile proportions reminiscent of mechanical keyboard switch caps.

## Semantic HTML

```html
<p>
  Press <kbd class="pl-c-kbd">⌘</kbd> <kbd class="pl-c-kbd">K</kbd> to open
  search.
</p>
```

## Class contract

| Selector    | Role                                                               |
| ----------- | ------------------------------------------------------------------ |
| `.pl-c-kbd` | Mechanical keycap with physical bottom border and bevel highlight. |
