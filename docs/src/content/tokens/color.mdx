Colors use OKLCH. Semantic colors use `light-dark()` to follow the active color
scheme. The tables below show the declarations from `02-tokens.css`; explicit
themes and forced-colors overrides live in `03-themes.css`.

## Brand ramp

Override the `--pl-brand-*` properties to change the brand palette. Semantic
accent colors refer to this ramp.

<TokenTable prefix="--pl-brand-" caption="Brand colors" />

## Semantic colors

Use semantic foreground and background pairs rather than choosing a raw brand
color for each component. For example, pair `--pl-color-accent` with
`--pl-color-accent-text`. Status colors have a fill, a background tint, and a
text color. The contrast tests check the intended text/background pairs in
both themes.

## Focus ring

The focus color changes with the color scheme. The offset and width control

## Enterprise theme palettes

Porchlight provides seven pre-baked enterprise palette presets via the `data-pl-palette` attribute declared on `:root`, `<html>`, `<body>`, or scoped to any subtree container. Each preset configures brand ramps, surfaces, text, borders, and accent colors with tested WCAG AA contrast in both light and dark modes:

| Palette    | Aesthetic                | Best Suited For                                           | Accent Tone (Light / Dark)                                            |
| ---------- | ------------------------ | --------------------------------------------------------- | --------------------------------------------------------------------- |
| `slate`    | Cool neutral gray        | B2B SaaS, developer tooling, workflow engines             | Indigo steel (`oklch(46% 0.1 250deg)` / `oklch(70% 0.1 250deg)`)      |
| `zinc`     | Crisp monochromatic      | Technical analytics, hardware consoles, terminal views    | High-contrast neutral (`oklch(22% 0 0deg)` / `oklch(92% 0 0deg)`)     |
| `midnight` | Deep nocturnal blue-gray | SOC/SIEM cockpits, dark-first monitoring dashboards       | Electric cobalt (`oklch(44% 0.15 275deg)` / `oklch(68% 0.15 275deg)`) |
| `emerald`  | Warm emerald green       | Fintech, banking, sustainability, wealth management       | Emerald green (`oklch(43% 0.12 155deg)` / `oklch(71% 0.13 155deg)`)   |
| `amethyst` | Vibrant deep purple      | AI / LLM observability, data science, evaluation consoles | Vibrant purple (`oklch(44% 0.14 305deg)` / `oklch(71% 0.14 305deg)`)  |
| `crimson`  | Vivid ruby/crimson       | Security, incident response, high-risk SOC triage         | Ruby crimson (`oklch(43% 0.15 25deg)` / `oklch(71% 0.15 25deg)`)      |
| `cyan`     | Electric cyan/teal       | Cloud infrastructure, Kubernetes clusters, telemetry      | Electric cyan (`oklch(42% 0.11 195deg)` / `oklch(71% 0.12 195deg)`)   |

Palettes automatically leverage CSS Relative Color Syntax where supported to derive dynamic `--pl-color-accent-hover` and `--pl-color-accent-subtle` values, and `@media (color-gamut: p3)` wide-gamut enhancements for vivid accents.
