Use the font, type-size, line-height, and tracking tokens to keep application text
consistent across enterprise SaaS and corporate applications. Values below come from
the framework CSS at build time.

## Font stacks and weights

The default stacks use system fonts. Load a variable font in your application
before changing its font-family and weight tokens.

<TokenTable prefix="--pl-font-" caption="Font defaults" />

## Type scale

The fluid sizes use `clamp()` to scale between small and large viewports.
`vi` is one percent of the viewport's inline size. The `rem` limits still
respect the reader's root font size.

The micro tier `--pl-text-2xs` (~10.5px–11.5px) is engineered specifically for
high-density data tables, keyboard shortcuts, sparkline labels, and timeline metadata.

## Line height

Use tighter line height for headings and labels, normal line height for body
text, and loose line height for longer prose.

## OpenType feature profiles

Enterprise SaaS applications require unambiguous character representation (distinguishing
`0` from `O`, and `1` from `l` and `I`) and tabular numerals for ledgers and financial tables.

## Text wrapping

The base layer applies `text-wrap: balance` to headings and `text-wrap: pretty`
to paragraphs. These are element styles, not custom properties.
