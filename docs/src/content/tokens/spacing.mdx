## Spacing

Spacing uses `rem` so it follows the reader's font-size preference. Standard
cards use `--pl-space-5` for their inset; app-surface variants use a tighter
inset. Use `--pl-space-4` for common layout gaps.

### Density presets

`comfortable` is the default. `compact` changes control geometry; `dense`
also compresses spacing and small text. Set `data-pl-density` on the region
that needs the change.
