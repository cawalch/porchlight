Reset

The porchlight.reset layer is minimal browser normalization — no normalize.css, no opinionated defaults. :where() keeps every rule at zero specificity so it is trivially overridable.

What it normalizes

  • box-sizing: border-box on everything.
  • color-scheme: light dark and 100% text-size adjust on html.
  • margin: 0 and min-block-size: 100dvb on body.
  • Replaced elements (img, svg, video) are block and width-constrained.
  • Form controls inherit font and color.
  • touch-action: manipulation on interactive controls (no 300ms tap delay).
  • table uses separated borders with zero spacing.
  • [hidden] is forcibly removed from the render tree.
