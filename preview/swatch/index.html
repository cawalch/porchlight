Swatch

A static color chip for palettes, token previews, and color metadata. The base rule renders a bordered box everywhere; the typedattr() enhancement reads data-color where supported.

Token fills

Set --pl-c-swatch-color to any token. These chips are decorative and sit next to visible labels.

AccentSuccessWarningDanger

Sizes

Set --pl-c-swatch-size on the instance.

Typed data-color enhancement

Where typed attr() is supported, data-color supplies the fill directly. Keep the token fallback for browsers without the enhancement.

In context

Swatches pair with descriptions, property lists, and table cells.
