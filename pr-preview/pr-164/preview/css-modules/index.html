CSS Modules

Stable Porchlight classes with optional app-local styles.

Both cards use the same component. The customized card adds a generated module class to change its padding and border through Porchlight tokens.

Default card

Porchlight supplies the spacing, surface, and border.

App-specific card

The module adds a larger padding token and the theme's accent border.

Server templates, HTMX fragments, and Alpine controls can keep ordinary Porchlight classes. CSS Modules are optional application tooling.
