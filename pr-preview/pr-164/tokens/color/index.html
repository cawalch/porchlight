Colors use OKLCH. Semantic colors use light-dark() to follow the active color scheme. The tables below show the declarations from 02-tokens.css; explicit themes and forced-colors overrides live in 03-themes.css.

Brand ramp

Override the --pl-brand-* properties to change the brand palette. Semantic accent colors refer to this ramp.

Semantic colors

Use semantic foreground and background pairs rather than choosing a raw brand color for each component. For example, pair --pl-color-accent with --pl-color-accent-text. Status colors have a fill, a background tint, and a text color. The contrast tests check the intended text/background pairs in both themes.

Focus ring

The focus color changes with the color scheme. The offset and width control the visible outline around keyboard-focused controls.

Focus ring defaults
TokenDefault value
--pl-focus-colorlight-dark(oklch(52% 0.14 82deg), oklch(72% 0.13 82deg))
--pl-focus-offset2px
--pl-focus-size2px
--pl-focus-glow-opacity85%
