Pattern

Record detail

An enterprise record with overview, activity, permissions, and billing sections and native in-page navigation.

experimental

Open full example →

Try the record-detail example.

This composition combines the app shell, page header, cards, description lists, and Section Navigation. A wide content container keeps navigation beside the record; narrow containers place it in ordinary document flow above the sections. Each card has a stable fragment ID for keyboard navigation and shareable deep links.
