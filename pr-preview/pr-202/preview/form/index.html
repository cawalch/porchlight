Two-column aligned form (CSS Subgrid)

Add data-layout="aligned" to an .pl-c-form to align label and input columns across fields using CSS Subgrid. Labels size dynamically to the widest label in the form without hardcoded widths or JavaScript, and collapse to a single column on narrow screens.

Used for urgent security notifications.

Reactive form validation summary

Live warning alert banner (.pl-c-form__summary) driven entirely by form:has(:user-invalid). When any field becomes invalid, the summary illuminates and the submit button reflects warning feedback.
